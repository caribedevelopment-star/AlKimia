## Visual direction
Al.Kim.ia combines cinematic real-time lighting, generative behavior, sculpture, architecture, climate and memory. The experience is intentionally abstract rather than literal.

## Entity source
`assets/source/BASEmodel.blend` is the approved sculptural source reference for the next Blender/Codex entity pass. The current browser build uses unified implicit Marching Cubes entities so the figures read as continuous biomorphic matter rather than assembled primitives.
